# 🚀 RAG with LangChain

This repository documents my hands-on learning journey in **Retrieval-Augmented Generation (RAG)** using **LangChain**. Instead of following tutorials, I'm implementing each core RAG concept individually to understand how modern AI applications retrieve, process, and generate context-aware responses.

The repository is continuously updated as I learn more advanced RAG techniques.

---

## 📚 Topics Covered

- 📄 Document Loaders
  - Text Loader
  - PDF Loader
  - Directory Loader
  - Web Loader

- ✂️ Text Splitters

- 🔍 Retrievers

- 🎯 Maximum Marginal Relevance (MMR)

- 🔎 Multi-Query Retriever

- 📦 Contextual Compression Retriever

- 🧠 Embedding Models

- 🗄️ Chroma Vector Database

- 🤖 LangChain Components
  - Prompt Templates
  - Chains
  - Output Parsers
  - Runnables

## 🎥 Featured Project

### Tube Chat AI

A simple RAG application that allows users to ask questions about a YouTube video using its transcript.
